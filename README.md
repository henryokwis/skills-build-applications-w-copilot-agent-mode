## OctoFit Tracker API

The Node.js API runs on port `8000`. In GitHub Codespaces, use:

```text
https://$CODESPACE_NAME-8000.app.github.dev
```

When `CODESPACE_NAME` is not set, use the local API base URL:

```text
http://localhost:8000
```

Verify the users and activities endpoints with:

```bash
curl http://localhost:8000/api/users
curl http://localhost:8000/api/activities
```
